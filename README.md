# hxyfront-62006 对戒配石台

面向珠宝镶嵌工作室的对戒配石前端：预置 14 颗裸石、4 张订单（每单两颗），在浏览器内完成配对、拆对、换石与存档。

## 配对规则

- 每单两颗：外形相同、克拉差 ≤ 0.02ct、色级差 ≤ 1 级（D–J）
- 挑石按克拉差最小优先；最优候选超出色级差、或已被其他订单占用，整次拒绝，已配对记录不动
- 拆对只释放本对两颗，其他订单不受影响
- 换石先把旧颗还原回池，再对整对重验；任一项不过则保留原对
- 数据只存浏览器 localStorage，刷新保留，可一键恢复出厂预置

## 业务文件

| 文件 | 职责 |
| --- | --- |
| `src/matching.ts` | 配对判定：规则常量、预置数据、自动配对 / 拆对 / 换石纯函数 |
| `src/storage.ts` | 存档：localStorage 读写、结构校验、恢复预置 |
| `src/PairingBench.tsx` | 页面：订单工作台、换石候选、裸石池与筛选 |
